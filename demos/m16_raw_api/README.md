# Typed Raw Python API Demo

This package demonstrates the dynamic API on the same sealed ownership and
conversion model used by typed declarations. It covers closed-record and nested
list conversion, method-style attribute/item/call operations, heterogeneous
typed kwargs, checked conversion failure, and automatic object release.

From this directory, run:

```bash
bash run.sh
```

The command finishes with:

```text
Python raw API demo: SIFR:9:resources=zero
```
