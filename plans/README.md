# Sifr Plans

This tree owns execution planning and review artifacts.

- `roadmap.md` is the authoritative execution roadmap.
- `phases/` contains stable, flat phase files plus `phases/index.md`.
- `issues/active/` contains active issue and ad hoc phase plans.
- `issues/archive/` contains completed, superseded, abandoned, or historical issue plans. Record `status: completed | superseded | abandoned` in each archived doc header.
- `reviews/active/` contains current review handoff artifacts.
- `reviews/archive/` contains retained historical review artifacts.

Durable architecture and accepted technical references belong in `internal_docs/`.
