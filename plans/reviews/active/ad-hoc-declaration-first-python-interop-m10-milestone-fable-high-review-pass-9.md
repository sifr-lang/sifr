## Non-blocking findings

1. **MEDIUM — spurious `internal compiler error` diagnostics when a poisoned binding initializes a later assignment (pre-existing interaction; the uncommitted change widens its entry points).** `value: MissingType[int] = 42` followed by `total: int = value + 1` (or plain `total = value + 1`) now emits `SIFR-INTERNAL-0001: failed initializer for 'total' did not emit a diagnostic` alongside the genuine SIFR-NAME-0003, because the new annotation-taint poisoning (`patterns_and_assignments.rs:464-469`) makes the binop suppression return `None` without emitting, which trips the `failed_initializer_taint` ICE guard (`patterns_and_assignments.rs:289-306`). The interaction itself predates this branch: `value: int = undefined_name` then `value + 1` produces the identical ICE on the shipped pre-M10 release (verified on both compilers). Always fail-closed — check exits nonzero and the root diagnostic is preserved — but users see "internal compiler error" for an ordinary typo. Expression-statement and condition contexts suppress cleanly (verified). Fix direction: let initializer-failure taint fall back to the poisoned operand's stored taint (or have suppression paths refresh `last_error_taint`), and add the initializer-context case to `test_poisoned_initializer_binding_suppresses_formatting_cascades`.
2. **MEDIUM (pre-existing, correctly filed)** — the class-field mutating-receiver clone bug: `self.helper.bump()` loses the receiver mutation (probe prints 0 on both this tree and pre-M10), and in the newly compilable dual-mutation shape `self.helper.absorb(self.stock)` the `mut`-argument mutation lands while the receiver-side mutation is lost (probe: `[1, 7]` / `0`). The follow-up issue `ad-hoc-class-field-mutating-receiver-place-semantics.md` scopes this properly (place-preserving receiver path, aliasing rule, indexed-place boundary, no depth-special-casing) — this satisfies pass 7's filing requirement and is explicitly outside M10 causation.
3. **LOW (carried, fail-closed, same follow-up bucket)** — check/build parity gaps: a mut argument alongside a same-root read fails at rustc E0502; a proven-index mut argument fails at rustc E0282. Never silent.
4. **LOW (carried)** — `crates/sifr_runtime/src/python.rs` sits at exactly the 900-line cap boundary (guardrail passes, but the next touch forces the split).
5. **LOW** — invalid *parameter* annotations are not poisoned (only ann-assign locals), so `def f(value: MissingType[int])` still produces a formatting cascade alongside the root error; harmless but inconsistent with the new suppression intent.
