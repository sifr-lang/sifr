Use this template when creating a scoped task (output is written into `/issues` folder):

## Issue Title

#### **Current Situation**

- What problem are you solving and why does it matter?
- What is the current situation (business-wise)?
- What is the current situation (tech-wise)? How does the code work?

#### **Desired Situation**

- What is the desired situation (busniess-wise)?
- Why the desired situation would be better?

#### **Suggested Solution**

- How do we want to make things work (tech-wise)?
- What changes are needed in the code?
