## Follow-up Boundaries

Post-M4 host limits and future follow-ups:

- Non-Unix signal status evidence, non-Unix `terminate` semantics, and Windows subprocess fixtures are intentionally host-limited in the supported-host matrix, not pending M4 implementation gaps.
- Optional subprocess text output error-handler parameters beyond strict decoding remain future API work; the M4 public text output path consumes text/i18n M1 explicit encodings without locale defaults.
- Dropping an unwaited sync `Child` now removes the generated child-table entry and drops the host child handle. It intentionally abandons observation and does not claim process kill, wait, process-group cleanup, descendant supervision, or non-Unix status mapping.
- If a future stdlib module re-exports a workload-annotated callable, mirror project-module re-export workload metadata in stdlib bootstrap export collection before relying on that shape.
