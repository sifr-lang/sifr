| Dependency | Terminal state | Rationale | Revisit rule |

| `hickory-resolver` | deferred-to-future-capability | TCP connect/address resolution uses `tokio::net::lookup_host`; custom resolver records and DNS policy are outside this substrate. | Future resolver issue must define record APIs, cache behavior, DNSSEC stance, host support, and deterministic fixtures. |
| `x509-parser` | deferred-to-future-capability | Public certificate subject/issuer/SAN display is outside TLS capability; TLS errors carry typed verification evidence and fingerprints only. | Future certificate-inspection issue must consume text/i18n Unicode/display decisions. |

| `reqwest`, `ureq`, `isahc`, `surf` | rejected | High-level HTTP clients belong to the future Sifr-native HTTP client capability. | Future client capability must build on this substrate, not wrap a policy-heavy client crate as stdlib. |
| `axum`, `warp`, `actix-web`, `rocket`, `tower-http` | rejected | Server framework behavior belongs to capability handoff. | capability handoff may evaluate implementation helpers only behind Sifr-owned public APIs. |
