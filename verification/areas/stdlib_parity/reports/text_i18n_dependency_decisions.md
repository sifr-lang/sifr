# Text/I18n Dependency Decisions

Status: translation-catalog capability complete. Encoding versions were checked during the text encoding capability. Unicode core versions and generated Unicode 17.0.0 tables were locked on 2026-06-06. Segmentation is aligned with Unicode 17.0.0. Locale IDs, formatting, plural rules, and collation use the ICU4X 2.3 stable family. Translation bundles use a first-party `.mo` compatibility parser.
