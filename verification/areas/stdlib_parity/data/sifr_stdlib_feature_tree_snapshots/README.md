# `sifr_stdlib` feature tree snapshots

These snapshots record representative generated-program stdlib feature shapes.
They are point-in-time validation evidence, not regenerated by the verification
runner.

They were generated with:

```bash
cargo tree -p sifr_stdlib -e features --no-default-features
cargo tree -p sifr_stdlib -e features --no-default-features --features regex
cargo tree -p sifr_stdlib -e features --no-default-features --features json
cargo tree -p sifr_stdlib -e features --no-default-features --features http
cargo tree -p sifr_stdlib -e features --no-default-features --features python
```

Local checkout paths are normalized to `<repo>/...` so validation diffs stay stable.
