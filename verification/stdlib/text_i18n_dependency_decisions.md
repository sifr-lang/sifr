# Text/I18n Dependency Decisions

Status: M0 baseline. Versions were checked against crates.io during the M0 implementation on 2026-06-06.

| Family | Crate(s) | Sifr abstraction | Unicode/version alignment | Panic/unsafe audit | Typed error mapping | License/MSRV/binary/platform impact | Deterministic tests | Supply-chain signal |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| Encoding | `encoding_rs 0.8.35` | Hidden behind `sifr.encoding.Encoding`, static label registry, `Encoder`, `Decoder`, and text I/O adapters. | WHATWG encoding data from crate; Unicode version not used as Sifr Unicode table source. | M1 scans wrapper and emitted code; no user bytes may reach `unwrap`/`expect`/`panic`; `unsafe` audit limited to crate boundary. | `DecodeError`, `EncodeError`, recoveries, exhausted-state errors. | `(Apache-2.0 OR MIT) AND BSD-3-Clause`, MSRV 1.36; default `alloc`; no CJK fast encode features in M1 to bound size. | Tier 0/Tier 1 alias, BOM, malformed byte, incremental, handler fixtures. | Maintained WHATWG-compatible Rust crate used by Gecko ecosystem. |
| Normalization | `unicode-normalization 0.1.25` | Hidden behind `sifr.unicode.normalize` and `is_normalized`. | M2 records exact data version from the crate lock; any skew with generated property tables blocks release. | M2 panic scan on wrapper/property integration and generated tables. | `UnicodeDataError` for invalid form or unavailable data where applicable. | `MIT OR Apache-2.0`, MSRV 1.36; small dependency footprint. | NFC/NFD/NFKC/NFKD fixtures mined from CPython and Unicode normalization tests. | `unicode-rs` family, broadly used. |
| Segmentation | `unicode-segmentation 1.13.3` | Hidden behind owned `graphemes`, `grapheme_indices`, `words`, and `word_boundaries`. | M2.5 records crate data version and aligns or blocks on skew with M2 Unicode tables. | M2.5 scan ensures byte indices are boundary-checked and no invalid slicing. | `UnicodeDataError` only for impossible boundary/table issues; normal iteration is infallible on valid `str`. | `MIT OR Apache-2.0`, MSRV 1.85; compatible with local Rust 1.94. | Combining mark, emoji, regional indicator, punctuation, whitespace, mixed-script fixtures. | `unicode-rs` family, widely used. |
| Locale IDs | `icu_locale_core 2.2.0` | Hidden behind `sifr.i18n.LocaleId` parser/canonicalizer. | ICU4X 2.2 data family; M3 records exact CLDR/Unicode data set from lock. | M3 wrapper avoids panics for user locale strings and maps parse failures. | `LocaleIdError`. | `Unicode-3.0`, MSRV 1.86; compatible with local Rust 1.94; cross-platform pure Rust. | Deterministic BCP47/LocaleId parse and canonicalization fixtures. | Unicode/ICU4X official project. |
| Number formatting | `icu_decimal 2.2.0` + data | Hidden behind `NumberFormatter`. | Uses ICU4X 2.2 compiled data; skew with locale/plural/date data blocks M3. | M3 scan for user-controlled format options and numeric values. | `FormatError`. | `Unicode-3.0`, MSRV 1.86; `compiled_data` increases binary size and is recorded in M3 snapshots. | Stable-locale number formatting fixtures. | Unicode/ICU4X official project. |
| Date/time formatting | `icu_datetime 2.2.0` + data | Hidden behind `DateTimeFormatter`. | Uses ICU4X 2.2 compiled data; M3 records exact data. | M3 scan for user date/time inputs and formatter construction. | `FormatError`. | `Unicode-3.0`, MSRV 1.86; compiled data size recorded in M3 snapshots. | Fixed timestamp/date fixtures across selected locales. | Unicode/ICU4X official project. |
| Plural rules | `icu_plurals 2.2.0` + data | Hidden behind `PluralRules` and M4 translation plural lookup. | Uses ICU4X 2.2 compiled data shared with M3. | M3/M4 scan for category selection and catalog plural integration. | `PluralRulesError`, `TranslationError`. | `Unicode-3.0`, MSRV 1.86; compiled data size recorded. | CLDR category fixtures and catalog plural fixtures. | Unicode/ICU4X official project. |
| Collation | `icu_collator 2.2.0` + data | Hidden behind `Collator`. | Uses ICU4X 2.2 compiled data; skew blocks M3. | M3 scan for comparator construction and user strings. | `FormatError` or dedicated collation construction error if split in M3. | `Unicode-3.0`, MSRV 1.86; compiled data size recorded. | Locale-specific ordering fixtures with deterministic data. | Unicode/ICU4X official project. |
| Translation catalogs | local `.mo` parser | Hidden behind `Bundle`/`Translator` backend importer. | Catalog-declared charset decoding consumes M1 encoding substrate; no Unicode table source. | M4 parser rejects malformed lengths, offsets, plural metadata, and never evaluates general expressions. | `CatalogParseError`, `TranslationError`. | First-party code; file-size guardrail applies; no host-specific dependencies. | CPython `.mo` magic/version/corrupt/endian/plural/context/fallback fixtures. | Local audited parser because backend scope is narrow and security-sensitive. |
| Modern message formatting | none | API leaves backend-neutral room only. | n/a | n/a | n/a | No dependency in this phase. | Deferred fixtures only. | Deferred until a dedicated backend issue. |
