## Classified waivers

| Surface | State | Rationale |
| --- | --- | --- |
| Full timezone-aware/calendar object parity in `datetime` (fold/zoneinfo/tz database semantics) | `unsupported` | Current runtime exposes deterministic naive-time and fixed-offset helpers without shipping CPython timezone database behavior. |
| Full `re` Match/Pattern object matrix (named groups, groupdict, iterator-level captures) | `unsupported` | Current `Match`/`Pattern` surfaces close high-value entry points but do not mirror every CPython capture-object API. |
| Decimal/Fraction-specific and context-sensitive numeric semantics in `math` / `statistics` | `unsupported` | Wave e1 targets shipped float/int behavior and typed error contracts, not CPython decimal-context integration. |
| SHA3/SHAKE constructor families and bytes-oriented digest APIs in `hashlib` | `unsupported` | Runtime currently closes the guaranteed algorithm set and explicit placeholders raise typed errors for unsupported families. |
